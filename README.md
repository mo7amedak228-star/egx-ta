# 📈 نظام التحليل الفني للبورصة المصرية

داشبورد لتحليل أسهم البورصة المصرية فنياً — سكانر، شارتات ومؤشرات،
باك تيست، ووضع لايف بإشعارات المتصفح أثناء جلسة التداول.

## الأقسام

- **🔴 لايف** — يراقب أسهمك ويحدّث نفسه كل بضع دقائق أثناء الجلسة،
  ويبعت إشعار من المتصفح أول ما تحصل إشارة
- **🏠 نظرة عامة** — اتساع السوق وأداء القطاعات
- **🔎 تحليل سهم** — شارت شمعي بالمؤشرات والدعوم والمقاومات + خطة تداول
- **🔍 السكانر** — فلترة 224 سهم بشروط فنية
- **🧪 الباك تيست** — اختبار أي استراتيجية على 3 سنين بيانات

## البيانات

Yahoo Finance برموز `.CA` — يومية، والشمعة الحالية بتتحدّث كل 15–20 دقيقة
أثناء الجلسة. كفاية للسوينج، مش كفاية للمضاربة اليومية السريعة.

## تنبيه

أداة تحليل فني آلي — **مش توصية استثمارية**. التحليل الفني بيرجّح
الاحتمالات، مبيضمنش نتيجة. متخاطرش بفلوس مش قادر تخسرها.
